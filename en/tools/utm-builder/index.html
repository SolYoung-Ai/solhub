How it works & limits

Existing query params on the target URL are merged, never overwritten.

  • Runs locally in your browser — input is never uploaded to any server.
  • No input history is recorded; refreshing clears everything.
  • Results are for reference — double-check critical data before relying on it.

FAQ

Where does my data go?

Nowhere. All computation happens locally via browser JavaScript.

Why does the result differ from another online tool?

Different implementations use slightly different boundary rules (e.g. word counting, encoding). This page documents its rules.

Can I copy or download the result?

Yes. Every tool has a copy button, and some support file downloads.
